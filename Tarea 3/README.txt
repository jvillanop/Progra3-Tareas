## PARA EJECUTAR EL PROGRAMA:

1. **Abrir la terminal en VS Code:**
   - Ir a **Ver > Terminal** o presionar `Ctrl + ñ`.

2. **Navegar a la carpeta donde está el archivo:**
   - Usar el siguiente comando:
     ```sh
     cd ruta/del/archivo
     ```
   - **Ejemplo en Windows:**
     ```sh
     cd C:\Users\TuUsuario\Documentos\
     ```
3. **Instalar las librerías de Graphviz Python:**
   -  pip install graphviz

4. **Ejecutar el script:**
   - En Windows:
     ```sh
     py arbolbinario.py
     ```
5. Para ejecutar cada opción ingrese el numero deseado y siga las instrucciones

6. Para ejecutar la opción 4 (carga desde un archivo) debe crear un archivo por ejemplo "numeros.txt" y la estructura del archivo debe ser :

10
5
15
3
7
12
18

Cada número debe estar en una línea separada sin caracteres adicionales.
Si el archivo contiene líneas con texto no numérico, el programa las ignorará y mostrará un mensaje indicando que fueron omitidas.

10, 5, 15   # Error: No deben estar separados por comas  
"3"         # Error: No deben estar entre comillas  
7.5         # Error: Solo se permiten números enteros  
texto       # Error: No se aceptan palabras o letras
